Until you add your own photos, this page shows real stock photos pulled
from the internet (via picsum.photos) so it never looks like an empty
placeholder. Drop your own JPG/PNG photos into this folder using these
exact filenames — they take priority automatically over the stock photo:

  hero.jpg       – full-bleed hero background photo
  story-1.jpg    – "How We Met"
  story-2.jpg    – "The Proposal"
  story-3.jpg    – "Save the Date"
  groom.jpg      – groom's circular portrait
  bride.jpg      – bride's circular portrait
  gallery-1.jpg … gallery-6.jpg – the gallery grid (click to enlarge)

Recommended sizes: hero.jpg at least 1600×1200px (landscape). All others
at least 800×800px. Keep each file under ~500KB for a fast-loading page.
No code changes needed — the page detects each photo automatically.
